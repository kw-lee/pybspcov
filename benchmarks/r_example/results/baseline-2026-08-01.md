Relative to the R sampler time, the JAX warmed median was 2.325238x as long on
CPU and 19.434244x as long on GPU; the GPU median was 8.357959x the CPU median.
These ratios are descriptive only because the timing scopes and runtimes differ.

The host was under high shared load, so the timings remain diagnostic and the
full warmed min/median/max are disclosed. The current sequential `p = 5` kernel
is slower than R on this run; that result motivates future batching and sparse
kernel work rather than a performance claim. Raw CSV and JSON artifacts remain
uncommitted and ignored.
