# v0.1 Baseline Benchmark Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Record a compact BM/SBM CPU/GPU float32/float64 scaling baseline and a human-readable report.

**Architecture:** Extend the existing public SBM runner in place so its default behavior remains compatible. Generate ignored JSONL records with the runner, then deliberately force-add the curated records and a single Markdown report.

**Tech Stack:** Python 3.12+, JAX 0.11, pytest, JSONL, Markdown

## Global Constraints

- Do not modify `src/pybspcov`.
- Measure `p = 25, 50, 100, 200` with `n = 3p`, density 0.05, burn-in 1, samples 2, warmed repetitions 3, and seed 20260803.
- Run BM and correlation-screened SBM on CPU/GPU with float32/float64.
- Do not claim statistical convergence, universal speedup, or equivalence.
